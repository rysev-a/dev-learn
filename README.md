# audio learn

Локальное приложение «слушай учебник»: книги → разделы → главы. Каждая глава — слайды, и у каждого слайда свой аудио-файл (абзац урока), плюс квиз на теорию в конце; в «Дискретной математике» — ещё и упражнения с вводом ответа. Голос — **kokoro-ru** (русский файнтюн Kokoro-82M, голоса Sveta / Masha / Dima), работает локально, без сети.

## Книги

Порядок — по плану курса ([course.MD](course.MD)): дискретная математика → Python → алгоритмы → архитектура компьютера → операционные системы → базы данных → Rust → JavaScript. Книга «Системный дизайн» из плана ещё не написана.

- **Дискретная математика** — 3 раздела (язык математики, счёт и логика, графы и вероятность), 10 глав по 13 частей: слайды + квизы + упражнения с вводом ответа
- **Изучаем Python** — 33 главы в девяти разделах: «Основы» (первая программа, типы, условия, функции), «Данные и циклы» (циклы, списки), «Словари и кортежи», «Классы» (классы, методы и свойства, наследование), «Исключения и файлы» (исключения, файлы, пути и форматы), «Итераторы и генераторы», «Функциональное программирование» (функции высшего порядка, замыкания и декораторы, functools и operator, itertools), «Стандартная библиотека» (collections/heapq/bisect, числа и случайность, дата и время, регулярные выражения, sys/argparse/logging/subprocess, dataclasses/enum/typing/copy, тестирование). и «Асинхронность» (потоки, процессы и GIL; asyncio: корутины и async/await; asyncio на практике). Слайды с подсветкой кода + квизы + код-упражнения к каждой главе, которые проверяются в Docker-песочнице
- **Алгоритмы: продвинутый уровень** — 10 глав по 10–12 минут: анализ сложности, списки, поиск и сортировки, хеш-таблицы, два указателя, деревья, графы, кратчайшие пути, динамическое программирование, жадные алгоритмы; слайды и квизы + код-упражнения на Python (79 заданий), где эффективность проверяется по-настоящему: подсчётом обращений к данным и входами, на которых квадратичное решение не укладывается в лимит
- **Архитектура компьютера** — 10 глав в четырёх разделах: «Логика и числа» (биты и вентили, числа в компьютере, текст и защита данных), «Процессор» (регистры и цикл команд, команды-стек-ассемблер), «Память и производительность» (иерархия памяти и кэш, конвейер, виртуальная память), «Ввод-вывод и параллелизм» (шины, прерывания, диски; многоядерность, когерентность, SIMD и GPU). Железо моделируется на Python: слайды с запускаемым кодом, квизы и 89 Docker-проверяемых заданий (сумматоры, дополнительный код, UTF-8, свой процессор и ассемблер, кэши, конвейер, TLB, MESI)
- **Linux: от шелла до ядра** — 4 раздела (файловая система и шелл, права/процессы/службы, сеть и хранение, изоляция и ядро), 10 глав по ~10 минут; слайды, квизы и 83 код-упражнения: системные идеи моделируются на Python (пути и ссылки, иноды, права и ACL, sudoers, планировщики процессов и CFS, юниты systemd, подсети и маршруты, LVM и RAID, версии и зависимости пакетов, cgroup и слои образов, load average и strace)
- **Базы данных: под капотом** — 4 раздела (модель и надёжность, скорость и хранилища, масштаб и согласованность, паттерны), 10 глав по ~10 минут; слайды, квизы и 81 код-упражнение: настоящие SQL-запросы выполняются в SQLite внутри песочницы (соединения, окна, транзакции, планы запросов и индексы), а внутренности баз моделируются на Python (WAL, LSM и фильтр Блума, репликация и кворумы, шардирование и кольцо хешей, кэши и CQRS)
- **Изучаем Rust** — 16 глав в пяти разделах: «Основы» (введение, владение и заимствование), «Данные и абстракции» (структуры и перечисления, коллекции, ошибки), «Язык глубже» (трейты и обобщения, замыкания и итераторы, времена жизни и умные указатели, модули/тесты/cargo, потоки), «Применяем» (алгоритмы курса на Rust, биты и эмулятор процессора, файлы/процессы/сокеты) и «Веб-сервер» (HTTP по байтам, маршрутизатор и пул потоков, данные и протокол PostgreSQL). Слайды с проверенным компилятором кодом, квизы и 143 упражнения: решение компилируется rustc в Docker-песочнице (образ `rust:1.97-slim`, без сети, только std)
- **Изучаем JavaScript** — 10 глав по ~8 минут: сложность, массивы и списки, поиск и сортировка, хеш-таблицы, два указателя, деревья, графы, кратчайшие пути, ДП, жадные алгоритмы

## Запуск

Backend (порт 8000, первый запрос к TTS загружает модель ~30–60 с):

```sh
cd backend && uv run uvicorn app.main:app
```

Frontend (порт 5173, проксирует /api → 8000):

```sh
cd frontend && npm install && npm run dev
```

Открыть http://localhost:5173

Для код-упражнений «Изучаем Python» нужен запущенный Docker и образ `python:3.13-slim` (`docker pull python:3.13-slim`); без него остальное приложение работает как обычно.

## Структура

```
backend/
  app/
    main.py        — FastAPI-приложение, подключает роутеры
    config.py      — все пути (данные, аудио, БД, модели)
    books/         — курс: router.py (API), service.py (БД, аудио), seed.py (сид)
    voice/         — озвучка: engine.py (kokoro-ru), download_model.py,
                     models/ (чекпоинты)
    exercises/     — проверка кода в Docker-песочнице: tasks.py (задачи),
                     runner.py (запуск), router.py (API)
    data/
      textbook/    — исходники уроков, по директории на книгу
      audio/       — сгенерированные wav
      say.db       — SQLite
  seed_textbook.py — CLI-утилита сида
frontend/          — React 19 + Vite
  src/slides/      — слайды по книгам: <book>/chNN.jsx (реестр — lib/slides.js)
  src/quizzes/     — квизы на теорию (реестр — lib/quizzes.js)
  src/exercises/   — упражнения с вводом ответа (дискретная математика)
  src/components/  — плеер, квиз, Exercises (ответы), CodePractice + CodeEditor (код, CodeMirror)
  src/pages/       — книги и главы
tasks/             — исходные планы курсов (algo, arch_oc, db_learn)
```

## Наполнение (новая книга)

Тексты лежат в `backend/app/data/textbook/<id>-<slug>/<slug>-NN.md`. Формат:

```
#BOOK <id>                     ← необязательно, по умолчанию 1
#SECTION <название раздела>
#CHAPTER <номер> | <название урока>
<текст урока одной строкой, абзацы — литеральными \n\n>
```

Новая книга добавляется **только со слайдами** — полный чек-лист в `AGENTS.md`.
Сид (идемпотентно: готовые .wav не пересоздаются):

```sh
cd backend
uv run seed_textbook.py                # БД + недостающее аудио
uv run seed_textbook.py --no-audio     # только перестроить БД
uv run seed_textbook.py --audio-only   # только догенерировать аудио
```

Модель kokoro-ru скачивается один раз: `cd backend && uv run python -m app.voice.download_model` (~640 МБ).

## API

- `GET /api/books` — список книг со счётчиками (разделы / уроки / части)
- `GET /api/books/{id}/course` — дерево разделов и глав книги
- `GET /api/chapters/{id}` — глава с частями, текстами и длительностями
- `GET /api/lesson/{id}/audio` — аудио части
- `GET /api/lesson/{id}/download` — скачать часть
- `GET /api/chapters/{id}/download` — скачать главу целиком (части склеиваются в один wav)
- `GET /api/exercises/{book}/{chapter}` — код-упражнения главы (без тестов)
- `POST /api/exercises/run` — проверить код в Docker-песочнице (python:3.13-slim, без сети, с лимитами)
