#BOOK 10
#SECTION Знакомство с Rust
#CHAPTER 8 | Структуры, перечисления и Option без страха
Изучаем Rust. Глава 8. Структуры, перечисления и Option без страха. Чисел, строк и векторов хватает на маленькие программы. В больших нужны собственные типы: пользователь, точка на плоскости, цвет, статус заказа. В питоне для этого пишут классы. В расте классов нет, а есть два простых строительных блока. Структура собирает несколько значений под именами в один тип. Перечисление описывает значение, которое может быть одним из нескольких вариантов. К ним добавляется блок имплементации, где живут методы. Вместе они закрывают почти всё, что вы привыкли делать классами.\n\nСтруктуру объявляют словом стракт, за ним идёт имя с заглавной буквы и список полей с типами: «стракт юзер, скобка, имя двоеточие стринг запятая возраст двоеточие ю-тридцать-два запятая, скобка». Экземпляр создают, указав значение каждого поля по имени: «юзер скобка имя двоеточие стринг-фром аня запятая возраст двоеточие тридцать скобка». Обращаются к полю через точку: «юзер точка имя». Порядок полей при создании не важен, но указать нужно все. Структура — это новый тип, и компилятор не даст перепутать пользователя с адресом.\n\nСтруктуру с полями можно менять только если она объявлена с мут: тогда любое поле изменяется присваиванием, а отдельно сделать поле изменяемым нельзя. Есть два приёма, которые экономят код. Первый — сокращённая запись: если имя переменной совпадает с именем поля, пишут только имя. Второй — синтаксис обновления: «точка точка старый» копирует остальные поля из другого экземпляра. Чтобы структуру можно было печатать для отладки, над объявлением добавляют атрибут «дерайв дебаг», тогда формат с вопросом выведет все поля. Такие атрибуты называют выводимыми трейтами.\n\nМетоды пишут в блоке имплементации: «импл юзер, фигурная скобка», внутри — функции, у которых первый параметр называется селф. Он означает «тот экземпляр, у которого вызвали метод». Запись «амперсанд селф» говорит, что метод только читает данные, и вызывается он привычно: «юзер точка приветствие скобки». В теле поля берутся через «селф точка имя». Методы возвращают значения так же, как обычные функции. Структура и метод вместе создают знакомую картину: данные и поведение рядом, только без наследования и без скрытых полей.\n\nЕсли метод должен менять поля, первым параметром пишут «амперсанд мут селф». Тогда вызывать его можно только у изменяемой переменной. Есть и третья форма — просто «селф»: метод забирает экземпляр целиком, и использовать его после вызова больше нельзя. Это редкий случай, о нём мы поговорим в главе про владение. Кроме методов, в имплементации бывают ассоциированные функции без селф. Самая известная называется нью: «юзер двоеточие двоеточие нью скобка аня запятая тридцать скобка». Это обычный конструктор, но язык не требует особого имени, нью — всего лишь договорённость.\n\nБывают структуры без имён у полей, их называют кортежными: «стракт цвет скобка ю-восемь запятая ю-восемь запятая ю-восемь скобка». Поля у них номера: «цвет точка ноль». Они нужны, когда имена были бы лишними, а различать типы нужно. Метры и футы — оба число, но разные типы, и сложить их по ошибке нельзя. Есть и структуры совсем без полей, юнит-структуры, которые нужны как маркеры. Для обычных данных используйте структуру с именами полей: код с ней читается намного лучше, чем с набором безымянных значений.\n\nПеречисление описывает значение, которое принимает один из заранее перечисленных вариантов. «Энам направление, скобка, вверх запятая вниз запятая влево запятая вправо, скобка». Значение создают через имя типа и вариант: «направление двоеточие двоеточие вверх». Это точнее, чем строки или числа: нельзя случайно написать «вверху» или передать число семь вместо направления. Компилятор знает все варианты и проверяет, что вы обработали каждый. Энамы в расте похожи на перечисления из других языков, но умеют намного больше, чем простые константы.\n\nКаждый вариант перечисления может нести данные. «Энам фигура, скобка, круг скобка эф-шестьдесят-четыре скобка запятая, прямоугольник скобка эф-шестьдесят-четыре запятая эф-шестьдесят-четыре скобка, скобка». Круг хранит один радиус, а прямоугольник — две стороны. Разные варианты имеют разные данные, но вместе это один тип «фигура». В питоне для такого пришлось бы писать несколько классов с общим предком. В расте всё в одном месте, и компилятор следит, чтобы данные соответствовали варианту. Размер значения равен самому большому варианту плюс метка.\n\nРаботать с перечислениями удобнее всего через матч, который мы встречали в пятой главе. «Матч фигура, круг скобка р скобка стрелка пи умножить на р в квадрате, прямоугольник скобка а запятая б скобка стрелка а умножить на б». В образце можно сразу достать данные варианта в переменные. Компилятор проверяет, что учтены все варианты: добавьте новый вариант, и каждый матч, который его не обрабатывает, перестанет собираться. Это превращает добавление нового случая из рискованного дела в безопасную подсказку компилятора: он покажет все места, где нужно что-то поменять.\n\nСамое важное перечисление в расте называется оптион, и мы уже несколько раз его видели. У него два варианта: сам со значением внутри и нон без значения. Это замена нулевого значения. В большинстве языков любая ссылка может оказаться пустой, и программа падает, когда об этом забывают. В расте значения, которое может отсутствовать, имеют тип оптион, и компилятор не позволяет использовать его как обычное, пока вы не проверите. Работать с оптионом можно через матч, через иф-лет, через методы анврап и анврап-ор, который подставляет значение по умолчанию.\n\nРядом с оптион есть его брат — резалт. У него варианты ок со значением и эрр с ошибкой. Именно его возвращает парс, когда превращает строку в число: «пять» даст ок с числом пять, а «пять-пять» — эрр с описанием проблемы. Резалт мы подробно разберём в главе про обработку ошибок, а пока полезно знать, что он тоже работает с матчем и методом анврап. Идея одна: операция, которая может не получиться, прямо говорит об этом в типе, и невозможно просто забыть проверить результат, как забывают код ошибки в сях.\n\nСравним с питоном. Класс с полями превращается в структуру, методы — в блок имплементации, конструктор — в функцию нью. Дата-класс похож на структуру с дерайв-атрибутами. Наследования нет, вместо него трейты, которые мы изучим позже. Энам в питоне — набор констант, в расте — полноценный тип с данными в вариантах. Значение нон превращается в оптион, а исключения — в резалт. В расте вы не получите ошибку «у нон нет атрибута»: до этого не дойдёт, потому что компилятор не пропустит такую программу.\n\nПодведём итоги. Структура — именованные поля, метод пишется в блоке имплементации, селф читает, мут селф меняет. Ассоциированная функция нью создаёт экземпляр. Перечисление задаёт один из вариантов, каждый вариант может хранить данные, а матч обрабатывает все. Оптион заменяет пустое значение, а резалт — исключения. Это первая часть знакомства с языком: теперь у вас есть переменные, типы, функции, ветвления, циклы, строки, коллекции и собственные типы. В следующем разделе мы сравним питон и раст на всех этих темах по очереди, чтобы закрепить знания.
