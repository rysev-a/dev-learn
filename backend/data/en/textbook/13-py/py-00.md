#CHAPTER 0 | What a programming language is and why Python
Python as a first language. Introduction. What a programming language is and why Python. Before you write your first line of code, it helps to see the whole picture. What is a program? What does it mean to have a programming language, and why do we need one? Why did we pick Python for a first acquaintance? And which building blocks does every language have: variables, conditions, loops, functions, classes? In this introduction we won't type any code. We will simply meet the ideas that we will master step by step, chapter by chapter. Don't be put off by unfamiliar words: each of them will get its own chapter, its own examples and its own exercises.\n\nA program is a precise sequence of commands that a computer carries out. Like a recipe for a dish: take, mix, heat, wait. But a recipe has a reader with intuition, and a computer has none. It does exactly what is written, fast, without getting tired and without common sense. Any imprecision turns into a bug. A person thinks in phrases and images, while a processor understands only numbers, encoded commands: add, copy, compare, jump. We need a go-between that both sides can agree on. Such a go-between is called a programming language.\n\nProgramming languages come at different levels. The lowest level is machine code: rows of zeros and ones that the processor executes directly. Above it sits assembly language: the same commands, but with short names instead of numbers. Higher still are high-level languages such as Python: you write things like open a file and loop over the lines, instead of moving individual memory cells around. The higher the level, the less code you need and the clearer it is, but the further it is from the hardware. In the end, every high-level language turns into processor commands, and a special translator program does that work.\n\nTranslators come in two kinds. A compiler translates the whole program in advance and produces a ready-to-run executable file. That is how C and Rust work: the program is fast, but between an edit and a run there is a pause for the build. An interpreter reads the program and carries it out step by step, right now. That is how Python works. You type a line, press run, and see the result immediately. That is why Python is so good for experimenting: you can open an interactive console, enter an expression, get the answer, and try something else right away. For a beginner, this kind of feedback is priceless, because mistakes are found within seconds.\n\nThere are other differences between languages too. In a language with static typing, the type of each variable is declared in advance, and the compiler checks that everything fits together before the program runs. In Python, typing is dynamic: a variable gets its type from the value that sits in it, and the checks happen while the program is running. Languages also differ in style. In the procedural style, a program is a set of steps and functions. In the object-oriented style, it is a set of interacting objects. In the functional style, it is a composition of data transformations. Python doesn't force one style on you: you can write in any of them, and that is one more reason it suits learning.\n\nWhy did we choose Python? First, it reads almost like English: fewer symbols and brackets, and the required indentation makes you format your code neatly. Second, it is one of the most popular languages in the world. It is consistently near the top of the rankings, so you will have textbooks, a community and ready-made libraries for every occasion. Third, the standard library already covers files, time, networking and text, which is why people say that batteries are included. And finally, the barrier to entry is low: a simple program takes one line, and a complex one can be grown gradually.\n\nWhere is Python used? On the web: it powers the server side of websites and programming interfaces, and frameworks such as Django, Flask and FastAPI are well known far beyond the Python world. In machine learning and data analysis: NumPy, pandas, PyTorch and scikit-learn have become industry standards, and most neural networks today are trained in Python. In automation and system administration: scripts that rename files, parse logs and put together reports. In many operating system utilities: package installers, build tools, configuration tools. Python also shows up in science, finance, games and testing.\n\nA first language is not only a tool, but also a way of thinking. The ideas you pick up in Python carry over: a variable, a condition, a loop, a function and a class work the same way in any language. Once you have learned them, you will be able to read code in different languages, noticing only the difference in syntax, like dialects of one language. That is exactly why Python comes first in this course, followed by algorithms, computer architecture, C, Unix and Rust. By the time you need the strictness of a compiler and delicate work with memory, you will already have a solid foundation.\n\nEvery programming language has five basic building blocks. Data: numbers, text, collections, and the names under which we store them. Actions: calculations and operations on data. Control: conditions that choose a path, and loops that repeat steps. Reuse: functions that gather a set of steps under a single name. And modeling: classes that combine data and behavior into a single object. Next we will take a brief look at each of these blocks, so that in the coming chapters you recognize old friends instead of discovering something unknown.\n\nA variable is a name under which a value is stored. Say that age equals thirty-four, and a number appears in memory, while the name age points to it. You can read the value, replace it, and use it in calculations. Values have types: whole numbers, fractional numbers, strings, and the logical values true and false. Simple values are combined into collections: a list holds a sequence, a dictionary links keys with values, and a set holds unique elements. It is important to know the type of a value, because it decides which operations are allowed, and every program starts with exactly this.\n\nA program has to be able to make decisions and repeat actions. A condition chooses a path: if the temperature is above thirty, print hot, otherwise print pleasant. A loop repeats steps: for each number in a list, add it to the total, until the data runs out. These two constructs are the basis of almost every algorithm: search, sorting, counting. Python marks the body of a condition or a loop with indentation, so the structure of a program is visible at a glance. You need to be careful here: a mistake in indentation changes the meaning of the program, but that same strictness is what makes code uniform and readable.\n\nA function is a named set of actions that you can call many times. You describe once how to calculate the area of a circle, and from then on you write one word instead of ten lines. A function has parameters, that is, its inputs, and a result that it returns. Functions remove repetition, make code shorter, and let you test each part separately. A good function does one task and has a clear name. Big programs are built from small functions, like from the parts of a construction set, and this skill is what distinguishes a programmer from someone who just writes scripts.\n\nA class is a blueprint from which objects are created. An object combines data, which we call attributes, and actions, which we call methods. The class dog describes that every dog has a name and an age and that it can bark, while the particular dogs Sharik and Rex are objects created from this blueprint. Classes help to model a subject area: a user, an order, a bank account. Large programs are organized through them, and inheritance lets you build new classes on top of existing ones. In Python almost everything is an object, even numbers and functions, and this gives the language its uniformity.\n\nLet's sum up. A programming language is a go-between for a human and a processor, and Python is a high-level language that is run by an interpreter. We chose it for its readability, its popularity, its rich standard library and its low barrier to entry, and it is used in web development, machine learning, automation and system utilities. Every language has variables, conditions, loops, functions and classes, and those are exactly what we will study in the following chapters. You have to learn by doing: type the examples yourself, read the error messages, solve the exercises. In the next chapter we will run our first program and see how all of this works in practice.
