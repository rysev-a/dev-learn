#CHAPTER 7 | Multiplexers and buses
Computer Architecture. Chapter 7. Multiplexers and buses. A computer is constantly deciding which signal to send where: which register to read, which memory cell to write to, which operation to perform. There are four families of circuits for this. A multiplexer chooses one of several inputs and sends it to the output. A demultiplexer does the opposite: it directs one input to one of the outputs. A decoder turns a number into a single lit line, and an encoder restores the number from the lit line.\n\nA two-to-one multiplexer has two data inputs A and B, a selector S, and one output Y. If the selector is zero, A goes to the output, and if it is one, B does. The formula: Y equals not S times A, plus S times B. It is a circuit of three gates and an inverter. In the practice you will build different variants: one without an inverter, an inverting multiplexer, where the output is the opposite of the chosen input, and a multiplexer made only of NOR gates.\n\nOften an enable input is added to a multiplexer. While the enable is zero, the output stays silent and holds zero, and when it is one, the circuit works as usual. Such an input is needed to switch off unneeded blocks. A multiplexer can also be used for unusual tasks. Feed the signal B and its negation to the data inputs, and the signal A to the selector: you get a controllable inverter, that is, exclusive OR. If A is zero, the signal B passes as is, and if A is one, it is inverted.\n\nA four-to-one multiplexer chooses one of four inputs using a two-bit selector. It is easiest to build as a tree: two first-level multiplexers choose from pairs of inputs by the low bit of the selector, and a second-level multiplexer chooses between their outputs by the high bit. In the same way, eight-to-one, sixteen-to-one and larger multiplexers are built from two-to-one multiplexers. The number of gates grows linearly with the number of inputs, and the depth grows logarithmically.\n\nSo far we have been choosing single bits, but data in a computer is transferred in words. A group of wires that carries a whole word is called a bus. A two-bus multiplexer consists of several identical multiplexers, one for each bit, and they share the selector. One selector bit switches the entire word at once. In the following chapters this is exactly how the processor chooses which of the values to feed to the adder or write to a register.\n\nA one-to-two demultiplexer directs the input signal to one of two outputs. The output whose number matches the selector gets the signal, and the other stays zero. The formulas: Y zero equals A times not S, and Y one equals A times S. These are two AND gates with a shared inverted selector. A demultiplexer is needed when one value must be written to one of several places, but not to all at once.\n\nA two-to-four decoder receives a two-bit code and lights exactly one of four lines. The code zero zero turns on line zero, zero one turns on line one, one zero turns on line two, one one turns on line three. Each output is an AND gate of the inputs in the right polarity. Such a selection is called one-hot code: of four wires, one is lit. Decoders select a memory cell by address, a register by number, and an instruction by opcode.\n\nA decoder with enable can also be considered a demultiplexer. If you feed data to the enable and a code to the address, you get a one-to-four demultiplexer: the data goes only to the selected line. From two two-to-four decoders and one extra bit you can build a three-to-eight decoder: the high bit chooses which of the two decoders works. This is how the address size is increased without changing the design of the basic cell.\n\nA four-to-two priority encoder works the other way around: four lines come in, and the output is the two-bit number of the lit line. And what if several are lit at once? For this, priority is introduced: the highest line wins. An additional output shows that at least one input is active, otherwise the code zero zero cannot be told apart from line zero. Encoders are used in interrupt controllers and in keyboards.\n\nThe multiplexer is universal. If you feed the constant values from a truth table to the data inputs of a two-to-the-N-to-one multiplexer, and the input variables to the selector, you get any function of N variables. A four-to-one multiplexer with inputs zero, one, one, zero gives exclusive OR. And that means the whole set of gates can be built from one type, for example from NOR. This will come in handy when we build the ALU and memory from a limited set of parts.
