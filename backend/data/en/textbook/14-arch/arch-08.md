#CHAPTER 8 | Latches and First Memory
Computer Architecture. Chapter 8. Latches and First Memory. The circuits from the previous chapters are combinational: their output is fully determined by the current inputs, and they need no memory. But a computer has to remember: the values of variables, the address of the next instruction, the result of the previous step. A circuit whose output depends not only on its inputs but also on the past is called sequential, and what it remembers is called its state. The basic trick that lets a circuit remember is very simple: send the output back to the input, that is, close a feedback loop.\n\nTake two inverters and connect them in a ring: the output of the first goes to the input of the second, and the output of the second goes to the input of the first. Such a pair has two stable states. Either the first one outputs a one and the second a zero, or the other way around, and each state holds itself in place. The circuit will remember one bit for as long as you like. The catch is that with no extra inputs you cannot write a new value into it. That is why the inverters are replaced with gates that have two inputs, one of which stays free for control.\n\nIf you replace the inverters with NOR gates, you get an S-R latch. It has two inputs: S, set, and R, reset, and two outputs, Q and not Q. A one on S sets Q to one, and a one on R resets Q to zero. When both inputs are zero, the latch remembers the previous value. But ones on both inputs at once are forbidden: both outputs drop to zero, and after the signals are removed the state is unpredictable. This first memory takes just two gates.\n\nAn S-R latch can also be built from NAND gates. Such a latch works with inverted inputs: the active level is zero, not one. A zero on the set input turns Q on, a zero on the reset input turns it off, and two ones mean: change nothing. The choice between the two versions depends on the technology: in CMOS, NAND gates are more compact, while in teaching circuits NOR gates are easier to read. In the practice section you will build both versions and see that their behavior differs only in polarity.\n\nWhat do we do about the forbidden combination? We can add a priority. If set has priority, reset is let through only when set is zero: R prime equals R times not S. Then ones on both inputs result in a set. If reset has priority, it is the other way around, and set is blocked whenever R is one. Priority is needed wherever two events can arrive at the same time, and the designer has to decide in advance which of them wins.\n\nIt is convenient to add an enable to the S-R latch: two AND gates in front of the inputs pass the S and R signals only while the enable equals one. This way the latch can be controlled at the right moment. A classic application is an alarm. A sensor is connected to the set input, and a reset button to the R input. When the sensor triggers, even for an instant, the latch remembers the alarm, and the lamp keeps burning even after the sensor has been released. It goes out only when the button is pressed.\n\nThe inconvenience of the S-R latch is that you have to think about two inputs separately and about the forbidden state. The D latch removes this problem. It has a data input D and an enable input E. Inside is the same S-R latch with an enable, but S is fed with D, and R is fed with not D, so the forbidden combination is impossible. While E equals one, the latch is transparent: Q follows D. As soon as E becomes zero, the latch captures the last value and holds it, whatever happens on the D input.\n\nThere are many variants of the D latch. It can be built from NAND gates. You can add a clear input that forcibly resets the stored value. If you put two D latches side by side with a shared enable, you get a two-bit register: it remembers a whole word. And if you place a multiplexer in front of the D input, you can choose where the new value comes from, for example from one of two different sources. Processor registers are built from parts like these.\n\nNow let us build a memory cell. At its core is a D latch. The write enable goes through an AND gate together with an output of the address decoder: writing happens only into the selected cell. For reading, another AND gate is added: the value reaches the shared line only from the cell chosen by the address. So a decoder, several latches and read gates make a small random-access memory. The data arrives on a shared bus, and the address decides which cell accepts it.\n\nLatches have a drawback: while the enable is open, the latch is transparent, and any noise or short pulse on the input immediately passes to the output. If the output of a latch is fed back to its input through a chain of gates, races and oscillations are possible. To make writing happen at one strict moment, rather than throughout the whole window, clock signals and edge-triggered flip-flops were invented. They will be the topic of the next chapter, and for now, go build latches and try to break them.
