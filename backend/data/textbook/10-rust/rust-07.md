#BOOK 10
#SECTION Знакомство с Rust
#CHAPTER 7 | Кортежи, массивы и векторы
Изучаем Rust. Глава 7. Кортежи, массивы и векторы. До сих пор в каждой переменной жило одно значение. Но программам нужно хранить и много значений вместе: список оценок, координаты точки, строки таблицы. Для этого в расте есть составные типы. Кортеж собирает значения разных типов в одну группу фиксированного размера. Массив хранит значения одного типа, и размер у него тоже фиксирован. Вектор — это растущий массив, ближайший родственник питоновского списка. В этой главе мы разберём все три, их сходства и отличия, и научимся выбирать подходящий.\n\nКортеж записывают в круглых скобках: «лет точка равно скобка три запятая четыре точка пять запятая строка скобка». Его тип — перечисление типов в скобках, и он состоит из ай-тридцать-два, эф-шестьдесят-четыре и эс-ти-ар. Элементы достаются по номеру через точку: «точка точка ноль» и «точка точка один». Квадратных скобок здесь нет, потому что номер известен при сборке. Кортеж можно разложить сразу на переменные: «лет скобка икс запятая игрек запятая зет скобка равно точка». Пустой кортеж с нулём элементов мы уже встречали — юнит.\n\nМассив пишут в квадратных скобках: «лет а равно скобка один запятая два запятая три скобка». Его тип — «скобка ай-тридцать-два точка с запятой три», то есть тип элементов и длина. Длина входит в тип: массив из трёх элементов и массив из четырёх — разные типы. Запись «скобка ноль точка с запятой пять скобка» создаёт массив из пяти нулей. Массив лежит прямо в стеке без выделения памяти в куче, поэтому очень быстрый. Обратиться к элементу можно по индексу: «а скобка ноль скобка». Длину возвращает метод лен.\n\nЧто будет, если индекс выходит за границы? В расте — паника с понятным сообщением «индекс вышел за границы, длина три, индекс пять». В сях это привело бы к чтению чужой памяти и тихому повреждению данных, в питоне — к исключению индекс-эррор. Раст проверяет границы при каждом обращении по индексу и тем самым защищает программу. Если индекс известен при сборке, как в «а скобка десять скобка», компилятор отвергнет код ещё при сборке. Безопасный способ — метод гет, он вернёт значение или ничего, если индекса нет, и программа не упадёт.\n\nСрез — это ссылка на часть массива. «Амперсанд а скобка один две точки четыре скобка» — срез из элементов с первого по третий, правая граница не входит, как в диапазонах. Тип среза пишется как «амперсанд скобка ай-тридцать-два скобка»: без длины, потому что она известна только при работе программы. Срезы бывают у массивов, векторов и строк, и именно с ними работают большинство функций. Срез ничего не копирует, он просто указывает на начало и хранит длину. Менять срез можно только если он изменяемый, то есть «амперсанд мут». Поэтому функциям лучше принимать срез: тогда в них подойдёт и массив, и вектор, и часть вектора, достаточно поставить амперсанд.\n\nВектор, записывается «век, угловая скобка, ай-тридцать-два, закрывающая угловая скобка», создаётся макросом век: «вектор-макрос скобка один запятая два запятая три скобка». Пустой вектор делает «век двоеточие двоеточие нью». Он умеет расти: метод пуш добавляет в конец, поп удаляет последний и возвращает его, лен показывает количество элементов. Вектор хранит данные в куче, поэтому размер может меняться во время работы программы. Все элементы вектора одного типа, как у массива, в отличие от питоновского списка, в который можно положить что угодно.\n\nОбращение к элементам вектора такое же, как у массива: «в скобка ноль скобка». Выход за границы вызывает панику. Метод гет возвращает значение или ничего: «в точка гет скобка пять скобка» даёт нон, если элементов меньше. Методы ферст и ласт возвращают первый и последний элемент, тоже в обёртке, потому что вектор может быть пустым. Результат, который может оказаться «ничем», в расте записан типом оптион. Он принимает два значения: сам, если значение есть, и нон, если нет. Разбираться с ним подробно мы будем в главе про перечисления, а пока можно просто вызывать анврап.\n\nВектор перебирают циклом фор. Запись «фор икс ин амперсанд в» значит «просмотреть элементы, ничего не забирая». Если нужно менять элементы, пишут «амперсанд мут в», и икс становится изменяемой ссылкой: «звёздочка икс плюс-равно один». Звёздочка нужна, чтобы обратиться к самому значению, а не к ссылке. Если важен индекс, добавляют энумерейт. А метод айтер возвращает итератор, у которого есть много полезных операций: суммирование, максимум и минимум, поиск, преобразование и фильтрация. Они понадобятся вам в каждой программе.\n\nВектор можно менять по-разному. Метод инсерт вставляет элемент на позицию, ремув удаляет по индексу и возвращает удалённое, клир очищает вектор. Метод экстенд дописывает в конец элементы другого вектора. Контейнс проверяет, есть ли значение. Реверс переворачивает вектор на месте. Метод дедуп убирает соседние дубликаты, поэтому его обычно вызывают после сортировки. Все эти методы требуют, чтобы вектор был объявлен со словом мут: изменить неизменяемый вектор нельзя, как и неизменяемую переменную. Это защищает вас от неожиданных правок.\n\nСортировка вектора — метод сорт, он упорядочивает элементы на месте по возрастанию. Для сортировки по своему правилу есть сорт-бай и сорт-бай-кей: например, по длине слов или по убыванию. Дробные числа нельзя отсортировать методом сорт, потому что у них есть нан, и нужно использовать партиал-кмп. Максимум и минимум — методы макс и мин у итератора, они возвращают оптион. Сумму считает сам, а искать значение в отсортированном векторе можно бинарным поиском за логарифмическое время. Сортировка в расте быстрая и устойчивая.\n\nДвумерные данные хранят как вектор векторов: «вектор вектор ай-тридцать-два» — сетка, у которой каждая строка может иметь свою длину. Обращение к элементу — «сетка скобка строка скобка скобка столбец скобка». Для фиксированных размеров подойдёт массив массивов: «скобка скобка ай-тридцать-два точка с запятой три скобка точка с запятой три скобка» — матрица три на три без кучи. Вложенные циклы фор перебирают её строки и столбцы. Матрицы, поля игр и таблицы в программах хранят именно так, хотя для больших вычислений есть специальные библиотеки.\n\nСравним с питоном. Питоновский список растёт, в него можно класть любые типы и обращаться по отрицательным индексам. Вектор растёт, но у него один тип элементов и только неотрицательные индексы. Для разных типов вместе есть кортеж, для фиксированного размера — массив. Генераторы списков заменяются цепочками итераторов: «айтер, мап, фильтр, коллект». Срезы похожи, но не копируют, а указывают на часть данных. Зато у вас есть гарантия: каждый элемент вектора одного типа и размера, а значит, обработка быстрая и предсказуемая.\n\nПодведём итоги. Кортеж — разные типы, фиксированный размер, доступ по номеру через точку. Массив — один тип, фиксированный размер, в стеке. Вектор — один тип, растущий размер, в куче. Срезы дают ссылку на часть последовательности. Индексы проверяются, а метод гет возвращает безопасный результат. Перебирайте циклом фор, меняйте через мут, сортируйте методами сорт. В следующей главе мы познакомимся со структурами и перечислениями, которые позволят создавать собственные типы данных.
