# Статус озвучки

Состояние на 16.10.2026: **всё аудио удалено** (`backend/data/audio/` пуст), чтобы проект не весил. Озвучка будет
сгенерирована один раз в конце, когда готовы все главы всех книг. Пока слайды идут по виртуальным часам
(≈ 14 символов в секунду), а текст абзаца показывает окно «За кадром».

## Как будет устроена озвучка

- Каждый абзац урока — отдельный wav (`<uuid5>.wav`), id вычисляется из `AUDIO_PREFIX` книги, номера главы и номера
  абзаца (`backend/src/seed.rs`; прежняя реализация — `app/books/seed.py` в теге `legacy-react-python`).
- Генерация: движок — `voice/engine.py` (kokoro-ru; модель — `cd voice && uv run download_model.py`, ~640 МБ); скрипт, который
  читает `backend/data/textbook`, режет главы на абзацы и пишет wav в `backend/data/audio/<uuid5>.wav` (пропуская готовые),
  пишется к моменту озвучки по образцу `backend/seed_textbook.py` из тега `legacy-react-python`.
- Голос — kokoro-ru (`sveta`); одна глава (13 частей) синтезируется за 1,5–2 минуты.
- После озвучки `cues` в слайдах нужно пересчитать по паузам в wav (сейчас — по доле символов), а запущенный бэкенд
  перезапустить: он кэширует длительности.
