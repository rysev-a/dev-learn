## Как устроена озвучка

- Каждый абзац урока — отдельный wav (`<uuid5>.wav`), id вычисляется из
  `AUDIO_PREFIX` книги, номера главы и номера абзаца (`books/seed.py`).
- Сидер пропускает уже существующие файлы, поэтому дозапуск безопасен и
  продолжает с того места, где остановились.
- Голос — kokoro-ru (`sveta`); пока модель грузится и считает, процесс занимает
  до ~2.4 ГБ памяти; одна глава (13 частей) синтезируется за 1,5–2 минуты.

## Как досинтезировать

```sh
cd backend
uv run seed_textbook.py --audio-only      # только недостающие wav, БД не трогает
```

После любой правки текста абзаца его wav нужно синтезировать заново: сидер
пропускает существующие файлы и старое аудио «приклеится» к новому тексту. Для
перезаписи конкретных частей используйте движок напрямую
(`app.voice.engine.synthesize_to_wav`) и пишите во временный файл с заменой
после успеха. Если меняется число абзацев или номер главы — перегенерируйте
главу целиком (id частей зависят от номера главы и абзаца).

## Лишние файлы

В каталоге остались 310 wav (~400 МБ), на которые ничто не ссылается: это
следы прежних схем (озвучка целой главой одним файлом, до перехода на аудио по
слайдам, и старые номера глав Python до вставки главы «Функции»). Их можно
удалить: с БД они не связаны. Проверка «что не ссылается на БД»:

```sh
cd backend && uv run python - <<'EOF'
from app import config
from app.books.seed import lessons_from_db
ids = {l["id"] for l in lessons_from_db()}
orphans = [p for p in config.AUDIO_DIR.glob("*.wav") if p.stem not in ids]
print(len(orphans), "файлов")
EOF
```

Ещё в каталоге лежат 4 старых mp3 (прежний движок gTTS) — они тоже ни на что
не ссылаются.
