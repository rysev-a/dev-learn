# Рефакторинг кодовой базы: итоги, что хранить в БД, что дальше

Ветка `refactor/cleanup-typescript` (от релиза `release/1.0.0`). Проверки, которыми подтверждён каждый шаг:
`npm run typecheck` (tsc strict + `ts-guard`), `npm run slides:check` (отрисовка 3030 слайдов), `npm run lab:check`
(83 решения лабораторий), `npm run net:check` (79 решений сетевой лаборатории), `npm run build`, тесты бэкенда
(`cd backend && uv run python -m unittest discover -s tests -t .`), для раннера — одинаковый вывод на выборке задач до и после.

## 1. Что в кодовой базе

| Область | Объём |
|---|---|
| Фронтенд (`frontend/src`) | 738 файлов `.ts`/`.tsx`, ≈226 тыс. строк; слайды — 246 файлов глав и 338 файлов сцен (≈123 тыс. строк), стили — `App.css` (≈3,4 тыс. строк) |

## 2. Что сделано

**Дублирование убрано.**

- `slides/SlideFrame.tsx` — `makeSlide(рубрика, всего)` вместо 246 копий рамки слайда.
- `slides/widgets.tsx` — карточка `Node`, блок `Cmd`, стрелка `Arr`, подсветка `PyCode`/`makePyCode`/`RsCode` вместо ≈190 копий
  в файлах глав (39 глав «Python» и «Rust»).
- `slides/anim/dsl.ts` — единые конструкторы элементов сцены (`Tx`, `cell`, `box`, `Box`, `line`, `arrow`, `codeIn`);
  пакеты `hw`, `lx`, `rs`, `cl`, `jv`, `db`, `ad` — тонкие надстройки; в пакеты переехали повторявшиеся в десятках файлов сцен
  `pair`, `nd`, `sm`, `lane`, `ev`, `year`, `grid`, `rsRow` (53 копии).
- Страницы: `lib/queries.ts` (кэш запросов), `lib/format.ts`, `lib/stats.ts` (подсчёт прогресса главы вынесен из страницы дашборда),
  `pages/chapters/context.ts` (типизированный контекст главы), `components/PracticeShell.tsx` (общая оболочка четырёх видов практики).
- Бэкенд: общий `_run_program` в раннере для режимов `c`, `rust`, `js`; сценарии сетевой лаборатории — общие `gw`/`route` в `scenarios/helpers.ts`.
- Слайды главы грузятся лениво (`import.meta.glob` + `BOOK_DIRS` в `lib/slides.ts`), а не одним пакетом.

**Мёртвый код удалён.** Неиспользуемые стили (проверено сборкой и обходом классов), неиспользуемые экспорты и локальные
объявления (≈210 штук по `noUnusedLocals`), ошибочные заглушки (`by` в `Arc04`, `reverse().reverse()` в `Arc10`).

**Найденные при типизации ошибки.**

- `CircuitView`: свойство `spread` затеняло одноимённую функцию (переименовано в `spreadYs`).
- `rsSpan` (врезки кода Rust в шести главах): регулярное выражение содержало вложенную группу и сдвигало номера групп, из-за чего числа
  красились как макросы, а ключевые слова и идентификаторы не подсвечивались вообще — теперь работает как задумано.
- `pySpan` в главах 1 и 5 «Python»: тот же сдвиг групп — одинарные кавычки красились как числа, ключевые слова не подсвечивались;
  исправлено единым токенизатором (в нём же f-строки).
- `row(…, {subSize})`: параметр передавался в 16 сценах, но тихо игнорировался — теперь действует.
- `dash: true` у линий и путей не включал пунктир (в CSS попадало `true`) — теперь `true` значит «3 3».

**Строгий TypeScript.** Весь `frontend/src` — `.ts`/`.tsx`, JS-файлов нет. `tsconfig.json`: `strict`, `noUnusedLocals`, `noImplicitReturns`,
`noFallthroughCasesInSwitch`, `noImplicitOverride`, `allowUnreachableCode: false`, `allowUnusedLabels: false`. `scripts/ts-guard.mjs`
запрещает явный `any` и `@ts-ignore`/`@ts-nocheck`/`@ts-expect-error` (сейчас 0 нарушений). Доменные типы: `types.ts` (API),
`netlab/types.ts`, `lab/…/blocks.ts`, `slides/anim/dsl.ts` (`SceneItem`, `Tone`, `Extra`), `slides/anim/alg.tsx`
(`SceneSpec`, `RowOpts`, `TreeNode`, `Pt`), `slides/anim/kit.tsx` (`StepsCtl`, `GraphNode`, `GraphEdge`).

## 3. Что можно хранить в БД

Сейчас в БД учебный текст и прогресс пользователей. В коде лежит то, что по природе является данными.

| Данные | Где сейчас | Предложение | Плюсы | Что сохранить в коде |
|---|---|---|---|---|
| Код-задачи: условие, заготовка, подсказка, эталон, тесты, скрытый `driver`, `flags`, `mode` | 170 тыс. строк Python в `*_tasks` | таблица `tasks (book, chapter, id, ord, mode, title, statement, starter, hint, solution, tests JSON, driver, flags JSON)` + `task_tags` | правка без перезапуска и деплоя; статистика решаемости, «трудные» задачи; импорт и экспорт; клиенту по-прежнему отдаются только условие, заготовка и подсказка | скрипт `verify_tasks` (эталон проходит, заготовка нет, в Docker) — прогон по строкам БД; генерация новых задач Python-функциями |
| Квизы | 1281 вопрос в `quizzes/*.ts`, весь пакет уходит клиенту | таблица `quiz_questions (book, chapter, ord, q, options JSON, correct, why)` | клиент получает только вопросы главы; проверка ответа на сервере (ответы не лежат в пакете); перемешивание позиций верного ответа; статистика ошибок по вопросам | проверка «верные ответы на разных позициях» — тестом сидера |
| Упражнения с вводом ответа (ДМ) | `exercises/dm.ts` | та же `tasks` с `mode = "answer"` | единый список заданий и прогресса | — |
| Манифесты лабораторий | `lab_manifest.json`, `net_manifest.json` (генерируются из TS) | строки `tasks` с `mode = "lab"` / `"net"` (id, название, условие) | один счётчик заданий для дашборда | сами движки схем и симулятор остаются в браузере |
| Метаданные книг | `BOOKS`/`AUDIO_PREFIX` в `seed.py`, `BOOK_DIRS` в `lib/slides.ts`, иконки в `BookIcon.tsx`, заголовки слайдов `SLIDE_TITLES_*` | колонки `books.slides_dir`, `books.icon`, `lessons.part_title` | новая книга — одна запись, без правки трёх мест | сами компоненты слайдов |
| Прогресс, попытки, черновики | уже в БД | дополнить событиями (`slide_views.dwell`, время решения) | аналитика дашборда | — |

Не переносить в БД: слайды и сцены (это React-компоненты и анимации), движки лабораторий, песочницу.

Порядок: 1) квизы (JSON, проверка на сервере, самый простой шаг); 2) метаданные книг; 3) задачи — сначала условия и подсказки, затем тесты и
драйверы с переключением раннера на чтение из БД; 4) манифесты.

## 4. Виджеты и утилиты: что осталось объединить

- `lab/react/AsmLab.tsx` и `RvLab.tsx` (≈250 общих строк: панель регистров и памяти, листинг, проверка, Tab в редакторе) → общая оболочка `AsmShell`.
- Жесты доски (панорама, масштаб, перетаскивание) продублированы в `GateBoard`, `BlockBoard`, `CircuitView` → хук `useBoardGestures`.
- Графовые помощники `GR` (Alg15), `WG` (Alg16), `TBL` (Alg18), локальный `LIST` в Alg19 (кроме `ad.LIST`) → `anim/graph.ts`.
- `bits` в `Arc04`/`Arc05`/`Arc18`, `seg` в `Vm05`/`Vm11`, `cells` в `Cl*`/`Rs07`/`Rs12` — одинаковые по смыслу, различаются подписью → пакеты книг.
- Python: общие шаблоны драйверов (`stdout`-задачи со скрытым `driver`) в `*_tasks` повторяются по главам → библиотека драйверов.

## 5. Дальнейшее ужесточение TypeScript

Включать по одному флагу, фиксируя количество ошибок:

| Флаг | Ошибок сейчас | Комментарий |
|---|---|---|
| `noPropertyAccessFromIndexSignature` | 47 | доступ к словарям только через `["ключ"]` |
| `exactOptionalPropertyTypes` | 198 | различать «нет поля» и `undefined` |
| `noUncheckedIndexedAccess` | 1375 | в сценах — тысячи индексов массивов; начать с `lib`, `pages`, `components`, `netlab` |
| запрет `!` и приведений `as` | ≈210 и ≈230 | заменять сужением типов и защитниками |

Для первых трёх удобно ввести второй проект `tsconfig.next.json` с флагом и снижать счётчик, не блокируя сборку.
